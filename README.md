# 📈 Investment Calculator

This is a React practice project built in **Section 5** of my training journey. It simulates an **investment calculator** where users can enter key financial details and see how their investment grows over time.

---

## 🚀 Overview

The project helps visualize investment growth using compound interest. Users can input:

- Initial Investment
- Annual Contributions
- Expected Annual Return (as a percentage)
- Duration in years

It calculates and displays yearly investment values, interest earned, and total capital in a tabular format.

---

## 🧠 Key Concepts Practiced

- **React State Management** with `useState`
- **Controlled Components** for form inputs
- **Props** to pass data and functions between components
- **Dynamic Rendering** with conditional logic
- **Data calculation and transformation**

---

## 🛠️ Tech Stack

- React (Vite)
- CSS3

---

## 📁 Main Components

- `App.jsx` — Main app logic and state handling
- `Header.jsx` — Displays app title and logo
- `Input.jsx` — Form to capture investment parameters
- `ResultsTable.jsx` — Displays calculated data in a table
- `investment.js` — Contains investment formula logic and currency formatting
