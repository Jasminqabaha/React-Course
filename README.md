# 🐛 Section 7 – Debugging React Apps

This project is based on the **Investment Calculator** built in [Section 5](https://github.com/Jasminqabaha/React-Course/tree/Section-5-react-essentials-practice-project). In this section, the focus was on learning how to effectively **debug React applications**.

---

## 🛠️ What We Practiced

- Using **React Developer Tools** to inspect components and state
- Tracking down **state update issues** and **data flow bugs**
- Validating props and component rendering
- Improving function structure and catching logic errors in the calculator

---

## 🔍 What's Different from Section 5

- Code was **cleaned up and improved** for better readability
- Logic bugs and miscalculations were fixed during the debugging process
- The project now provides more accurate validation feedback

---

> This project was not about adding new features, but about becoming confident with debugging tools and fixing broken or incorrect logic in existing React apps.
