# 🎨 React Styling Practice 

This project was built as a **practical exercise** to explore different techniques for styling components in React.

---

## 🚀 Overview

The app simulates a simple **auth form UI** (email & password inputs) with validation, styled using different CSS strategies including:

- **Tailwind CSS classes** (utility-first styling)
- **CSS Modules** (component-scoped styles)
- **Regular CSS**

---

## 💡 Key Concepts Practiced

- Using **TailwindCSS** for layout and utility-first styling
- Applying **conditional styling** based on validation state
- Organizing UI into **reusable components** (`Button`, `Input`, `Header`)
- Combining different CSS strategies (global CSS, CSS Modules, Tailwind)

---

## 🛠️ Tech Stack

- React (Vite)
- Tailwind CSS
- CSS Modules
- Regular CSS

---

## 📚 What I Learned

- How to mix styling methods in one React project
- Tailwind utility classes for rapid UI building
- How to dynamically change input styles based on form state
- When and how to use **CSS Modules** for local scope

---

> This is a design-focused exercise meant to strengthen styling skills in real-world React components.
