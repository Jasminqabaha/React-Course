# 🚀 React Learning Projects

This repository contains a collection of **React projects**, each developed in a separate branch.

These projects were created as part of my **learning journey** during training, with the goal of practicing and mastering core concepts of React such as components, JSX, props, state, and more.

Each branch focuses on a specific topic or concept in React, and includes a self-contained project to demonstrate its usage.

Feel free to explore the branches and see how each concept is applied in real examples!

It demonstrates:

- 📦 Passing data through **Props**
