# 📁 Section 9 – Practice Project: Project & Task Manager

This React project is a **project and task management tool**, built from scratch to apply core concepts like component design, state management, controlled/uncontrolled inputs, and modals.

---

## 🚀 Overview

Users can:
- Create and manage multiple **projects**
- Add, view, and delete **tasks** within each project
- Switch between different projects using a sidebar
- Interact with **modals**, **refs**, and **custom components**

---

## 🧠 Key Concepts Practiced

- 🧩 Component structuring and modular UI
- 📥 Controlled & uncontrolled form inputs (`useState`, `useRef`)
- 📌 Modal rendering and control via `useImperativeHandle`
- 🧠 Managing nested state objects with multiple update handlers
- 🗂️ Dynamic rendering of project lists, tasks, and empty states

---

## 💡 What I Learned

- Building a full CRUD-style interface in React
- Structuring state to support multi-level data (projects + tasks)
- Designing reusable, styled components

---

> This is a complete mini-app that demonstrates mastery of component-driven development in React.
