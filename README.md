# ⚙️ Section 13 – A Look Behind the Scenes of React & Optimization Techniques

This project is a **React counter app** built to explore how React renders components and how we can optimize performance using built-in hooks like `useMemo`, `useCallback`, and `React.memo`. The app includes a configurable counter, history tracking, and prime number checks.

---

## 🚀 Overview

Users can:
- Set a custom starting value for the counter
- Increment or decrement the count using icon buttons
- View whether the initial number is a prime
- Track their count history with selectable items

---

## 🧠 Key Concepts Practiced

- 🧠 Using `useMemo` to memoize expensive calculations (prime check)
- 🔁 Using `useCallback` to memoize event handlers
- 📦 Optimizing re-renders using `React.memo` and controlled component structure
- 🧩 Managing state across multiple components with clarity and efficiency
- 📋 Logging renders to understand performance impact

---

## 💡 What I Learned

- How React handles component rendering and when it re-renders
- How to profile and debug re-rendering behavior
- Applying `memo`, `useMemo`, and `useCallback` for cleaner and faster React apps
- Building responsive UI components with minimal re-renders

---

> This project offers a practical deep dive into how React works under the hood and how to write performant, scalable components.
